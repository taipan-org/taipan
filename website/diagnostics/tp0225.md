## What it means

A class is declared in a way Taipan doesn't allow. This code covers many rules about classes, and the message says which one was broken. The ones newcomers meet most are a method that doesn't take `self` first, which Python only reports when the method is called, and a class with more than one base class: Taipan has single inheritance, and uses protocols where Python would use a second base. Others include a dataclass field without a default after one with a default, and a special method (`__x__`) Taipan doesn't support.

## How to fix it

`increment` is missing `self`:

```taipan
class Counter:
    count: int = 0

    def increment():
        self.count += 1
```

```error
main.tpn:4:9: error TP0225: 'increment' must take 'self' first
  help: write 'def increment(self, …)'
```

An instance method takes `self` first, without a type:

```taipan
class Counter:
    count: int = 0

    def increment(self):
        self.count += 1

let c = Counter()
c.increment()
c.increment()
print(c.count)
```

```output
2
```

`Duck` lists two base classes:

```taipan
class Walker:
    def walk(self) -> str:
        return "walking"

class Swimmer:
    def swim(self) -> str:
        return "swimming"

class Duck(Walker, Swimmer):
    pass
```

```error
main.tpn:9:20: error TP0225: a class can have only one base class
  help: make the others protocols, or hold them as fields
```

Keep one base class, and make the other a protocol, which describes the methods a class must have. Protocols may be listed beside the base class:

```taipan
class Swimmer(Protocol):
    def swim(self) -> str: ...

class Walker:
    def walk(self) -> str:
        return "walking"

class Duck(Walker, Swimmer):
    def swim(self) -> str:
        return "paddling"

let d = Duck()
print(d.walk(), d.swim())
let s: Swimmer = d
print(s.swim())
```

```output
walking paddling
paddling
```
