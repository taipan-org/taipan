## What it means

A variant name is used on its own, but two enums have a variant with that name, so Taipan can't tell which one is meant. A variant can usually be written without its enum's name, as `Red` for `Light.Red`, but only while no other enum has a `Red` too. Taipan asks you to name the enum, even where the expected type is written out, rather than pick one for you.

## How to fix it

Both `Light` and `Signal` have a `Red`:

```taipan
enum Light:
    Red
    Green

enum Signal:
    Red
    Off

let light = Red
print(light)
```

```error
main.tpn:9:13: error TP0216: 'Red' is ambiguous: it is a variant of Light and Signal
  help: qualify it, e.g. 'Light.Red'
```

Write the enum's name in front. A variant only one enum has, like `Green`, still works alone:

```taipan
enum Light:
    Red
    Green

enum Signal:
    Red
    Off

let light = Light.Red
let signal = Signal.Red
print(light)
print(signal)
print(Green)
```

```output
Red
Red
Green
```
