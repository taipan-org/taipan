## What it means

The condition of an `if`, `elif` or `while` isn't a `bool`. In Python, any value can be a condition: an empty list, `0` and `""` count as false, everything else as true. Taipan asks for a real `True` or `False`, so that a condition says exactly what it tests. `if items:` could mean "not empty" or "not `None`", and it's easy to get wrong when the type changes.

## How to fix it

`names` is a list, not a `bool`:

```taipan
let names = ["Ada"]
if names:
    print("not empty")
```

```error
main.tpn:2:4: error TP0205: condition must be bool, found list[str]
  help: write 'len(x) > 0'
```

Write the test out. For a collection or string, compare its length; for a number, compare it with `0`:

```taipan
let names = ["Ada"]
if len(names) > 0:
    print("not empty")
let count = 3
if count != 0:
    print(count)
```

```output
not empty
3
```

For an optional, test `is not None`, or use `is some`. [Conditions are `bool`](../../language/control-flow/#conditions-are-bool) has the rule and its alternatives.
