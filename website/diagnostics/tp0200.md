## What it means

A value has a different type from the one the code needs there. Every value in Taipan has a type, such as `int`, `str` or `list[int]`, and each place a value goes has a type it accepts: a function's parameter, a variable declared earlier, an operator's operands. Python would find out only when that line ran, and fail with a `TypeError`; Taipan checks every one when the program compiles, so the mistake can't reach a user.

The message names both types: `expected int, found str` means the place accepts an `int` and was given a `str`.

## How to fix it

**Joining a string and a number.** `+` doesn't turn a number into text:

```taipan
let age = 36
print("age: " + age)
```

```error
main.tpn:2:7: error TP0200: operator '+' cannot be applied to str and int
  help: convert it with str(…), or use an f-string
```

Convert it with `str(…)`, or put it in an f-string:

```taipan
let age = 36
print("age: " + str(age))
print(f"age: {age}")
```

```output
age: 36
age: 36
```

**An argument of the wrong type.** `double` takes an `int`, and `"4"` is a `str`:

```taipan
def double(n: int) -> int:
    return n * 2

print(double("4"))
```

```error
main.tpn:4:14: error TP0200: expected int, found str
  help: parse it with int(…) or float(…), which give an optional
```

Pass a value of the right type. To turn text into a number, use `int(…)`, which gives `None` when the text isn't a number, so it needs a default:

```taipan
def double(n: int) -> int:
    return n * 2

let text = "4"
print(double(int(text) ?? 0))
```

```output
8
```

**A variable that changes type.** A `var` keeps the type of its first value:

```taipan
var count = 0
count = "none"
```

```error
main.tpn:2:9: error TP0200: expected int, found str
  help: parse it with int(…) or float(…), which give an optional
```

Give each kind of value its own variable, or, for "a number or nothing", declare it as an optional, `int?`, and use `None`:

```taipan
var count: int? = 0
count = None
print(count)
```

```output
None
```
