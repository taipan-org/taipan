## What it means

The value might be `None`, and the code uses it as if it can't be. Its type is an optional, such as `int?`, which holds either an `int` or `None`. Before an optional can be used as the value inside it, for arithmetic, a method, or an argument that needs an `int`, the program has to deal with the `None` case. Python would fail when that line ran with a `None`; Taipan catches it when the program compiles.

Optionals come from functions that may not have an answer: `dict.get`, `int("…")` and `float("…")`, and your own functions that return `T?`.

## How to fix it

Decide what should happen when there's no value. Here, `get` gives `None` for a missing key, so `age` is an `int?`:

```taipan
let ages = {"ada": 36}
let age = ages.get("bob")
print(age + 1)
```

```error
main.tpn:3:7: error TP0203: int? must be narrowed before use
  help: narrow it with 'is some', or give a default with '??'
```

Give a default with `??`, or check for a value with `is some`, which gives it a name inside the `if`:

```taipan
let ages = {"ada": 36}
let age = ages.get("bob")
print((age ?? 0) + 1)
if ages.get("ada") is some years:
    print(years + 1)
```

```output
1
37
```

`if age is not None:` works too, and inside it `age` is a plain `int`. [Optionals and narrowing](../../language/optionals/) has every way to check one.
