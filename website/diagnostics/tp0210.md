## What it means

The code reads a field or calls a method that the value's type doesn't have. The message names the type, so `list[str] has no method 'push'` means lists have no `push`. Usually it's a name from another language, a typo, or a field a class never declared. Python raises an `AttributeError` when that line runs; Taipan knows each type's members, so it reports the mistake when the program compiles.

## How to fix it

<!-- no help: 'z' is unlike any field of Point, so there's nothing to suggest -->

**A method or field from another language.** Lists add with `append`, and a length comes from `len(…)`:

```taipan
let names = ["Ada"]
names.push("Grace")
print(names.length)
```

```error
main.tpn:2:7: error TP0210: list[str] has no method 'push'
  help: write 'xs.append(x)'
main.tpn:3:13: error TP0210: list[str] has no field 'length'
```

```taipan
let names = ["Ada"]
names.append("Grace")
print(len(names))
```

```output
2
```

**A field a class doesn't declare.** Python lets you add an attribute to any object. In Taipan, a class lists its fields, and only those exist:

```taipan
class Point:
    x: int
    y: int

    def __init__(self, x: int, y: int):
        self.x = x
        self.y = y

let p = Point(1, 2)
p.z = 3
print(p.z)
```

```error
main.tpn:10:3: error TP0210: Point has no field 'z'
main.tpn:11:9: error TP0210: Point has no field 'z'
```

Declare the field in the class, here with a default so `__init__` needn't set it:

```taipan
class Point:
    x: int
    y: int
    z: int = 0

    def __init__(self, x: int, y: int):
        self.x = x
        self.y = y

let p = Point(1, 2)
p.z = 3
print(p.z)
```

```output
3
```

The [library reference](../../library/) lists each built-in type's methods, such as those of [`list`](../../library/list/) and [`str`](../../library/str/). [Fields must be declared](../../language/classes/#fields-must-be-declared) has the rule for classes.
