## What it means

A `const`'s value isn't a constant expression. A constant's value is fixed before the program runs, so it can only be built from literals: numbers, strings, `True` and `False`, combined with `+`, `-`, `*`, `/`, `//` and `%`. It can't use another constant, call a function, or be a list or dict, which can change. The same rule applies to a class attribute's value.

## How to fix it

Here one constant uses another, and one holds a list:

```taipan
const MINUTE = 60
const HOUR = MINUTE * 60
const ADMINS = ["ada", "bob"]
```

```error
main.tpn:2:14: error TP0217: const initializer must be a constant expression
  help: a const is a literal, or arithmetic on literals; use 'let' for a computed value
main.tpn:3:16: error TP0217: const initializer must be a constant expression
  help: a const is a literal, or arithmetic on literals; use 'let' for a computed value
```

Write the value out with literals, and use `let` for anything else. Functions in the main file can read a top-level `let`:

```taipan
const MINUTE = 60
const HOUR = 60 * 60
let admins = ["ada", "bob"]

def label(seconds: int) -> str:
    return f"{seconds // HOUR}h {seconds % HOUR // MINUTE}m"

def is_admin(name: str) -> bool:
    return name in admins

print(label(5400))
print(is_admin("bob"))
```

```output
1h 30m
True
```
