## What it means

A function defined inside another function has its own type parameters, as in `def show[T](…)`. Only top-level functions and classes can be generic. A nested function may still use the type parameters of the function around it. Because the nested function's own `T` isn't accepted, the calls to it usually report more errors after this one; they go away once it's fixed.

## How to fix it

`show` is nested inside `report` and takes its own `T`:

```taipan
def report(names: list[str], ages: list[int]):
    def show[T](label: str, xs: list[T]):
        print(label, len(xs))
    show("names", names)
    show("ages", ages)

report(["ada", "bob"], [36])
```

```error
main.tpn:2:14: error TP0223: nested functions cannot have type parameters
  help: declare it at the top level, or use the enclosing function's type parameters
main.tpn:4:19: error TP0200: expected list[T], found list[str]
main.tpn:5:18: error TP0200: expected list[T], found list[int]
```

Move the generic function to the top level:

```taipan
def show[T](label: str, xs: list[T]):
    print(label, len(xs))

def report(names: list[str], ages: list[int]):
    show("names", names)
    show("ages", ages)

report(["ada", "bob"], [36])
```

```output
names 2
ages 1
```

If the outer function is itself generic and the nested one only needs the same type, drop the brackets and use the outer `T`. [Functions](../../language/functions/) covers nested functions.
