## What it means

A type alias is defined in terms of itself. A `type` statement gives a new name to a type that already exists, and the compiler replaces the name with that type wherever it's used. An alias that refers to itself, directly (`type Tree = list[Tree]`) or through other aliases (`type A = list[B]` and `type B = A?`), would never finish being replaced, so there's no type for it to name.

## How to fix it

Here, `Tree` is meant to be a list of trees:

```taipan
type Tree = list[Tree]

let t: Tree = []
print(len(t))
```

```error
main.tpn:1:6: error TP0230: type alias 'Tree' refers to itself
  help: use a class for a recursive type
```

A class can refer to itself, because it's a type of its own rather than a name for another one. Make `Tree` a class with a field holding its children:

```taipan
@dataclass
class Tree:
    children: list[Tree]

let t = Tree([Tree([]), Tree([])])
print(len(t.children))
```

```output
2
```
