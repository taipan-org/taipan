## What it means

A protocol was used where a real class is needed. A protocol, a class that derives from `Protocol`, only lists the methods a type must have: any class with those methods satisfies it, without naming it. That makes it fine as the type of a parameter or a list's elements, but there's no object behind it. So it can't be constructed, and it can't be tested for with `isinstance`, `as`, a class pattern in `match` or an `except` clause, since there's no one class to look for.

A protocol whose methods mention `Self`, such as the built-in `Comparable`, is stricter still: it can't be a type at all, only the bound of a type parameter, as in `def f[T: Comparable](x: T)`, because each type it's used with compares only with itself.

## How to fix it

Construct a class that satisfies the protocol instead. Here, `Shape()` tries to make an object of the protocol itself:

```taipan
class Shape(Protocol):
    def area(self) -> float: ...

class Square:
    def area(self) -> float:
        return 4.0

let s = Shape()
print(s.area())
```

```error
main.tpn:8:9: error TP0229: 'Shape' is a protocol
  help: construct a class that satisfies it
```

`Square` has an `area` method, so a `Square` is a `Shape`, and can be passed wherever one is wanted:

```taipan
class Shape(Protocol):
    def area(self) -> float: ...

class Square:
    def area(self) -> float:
        return 4.0

def total_area(shapes: list[Shape]) -> float:
    var total = 0.0
    for s in shapes:
        total += s.area()
    return total

let s = Square()
print(s.area())
print(total_area([Square(), Square()]))
```

```output
4.0
8.0
```

For `isinstance`, `except` and patterns, test for `Square` rather than `Shape`. [Protocols](../../language/types/#protocols) has the rules, and bounded type parameters.
