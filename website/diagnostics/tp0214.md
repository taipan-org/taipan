## What it means

The same name is defined twice in the same place. In Python a second `def` or assignment quietly replaces the first; in Taipan each name in a block means one thing. A `let` can't be declared again to give it a new value, and two functions can't share a name, even with different parameters, since Taipan has no overloading.

## How to fix it

A second `let` with the same name is a duplicate:

```taipan
let price = 20
let price = price * 2
print(price)
```

```error
main.tpn:2:5: error TP0214: duplicate definition of 'price'
  help: give it another name; to change a value, assign to it without 'let'
```

Use `var` for a value that changes, and assign to it. Or give the new value its own name:

```taipan
var price = 20
price = price * 2
print(price)
let doubled = price * 2
print(doubled)
```

```output
40
80
```

Two functions with one name are a duplicate too:

```taipan
def area(side: float) -> float:
    return side * side

def area(width: float, height: float) -> float:
    return width * height
```

```error
main.tpn:4:5: error TP0214: duplicate definition of 'area'
  help: Taipan has no overloading: give it another name, or give the parameters defaults
```

Give each its own name:

```taipan
def square_area(side: float) -> float:
    return side * side

def rect_area(width: float, height: float) -> float:
    return width * height

print(square_area(3.0))
print(rect_area(2.0, 5.0))
```

```output
9.0
10.0
```
