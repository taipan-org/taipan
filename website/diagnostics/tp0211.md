## What it means

A function uses a variable from the top level of the file in a way Taipan doesn't allow. Functions may read a top-level `let` or `var`, but only one written directly at the top level, on a line of its own. A name that's created inside an `if`, a loop or another block, or by unpacking, might never be set at all, so a function can't rely on it. A parameter's default value can't use a top-level variable either, since defaults are worked out before the file's own code has run.

## How to fix it

Here `name` is created inside an `if`, so it only exists when the `if` runs:

```taipan
import sys

if len(sys.argv) > 1:
    let name = sys.argv[1]

def greet() -> str:
    return f"hello, {name}"

print(greet())
```

```error
main.tpn:7:22: error TP0211: 'greet' cannot use top-level variable 'name'
  help: it's bound inside a block or by unpacking; give it its own top-level 'let' or 'var'
```

Declare it directly at the top level, with a value it always has, and change it in the `if`:

```taipan
import sys

var name = "world"
if len(sys.argv) > 1:
    name = sys.argv[1]

def greet() -> str:
    return f"hello, {name}"

print(greet())
```

```output
hello, world
```

For a default value, use a `const`, which exists before anything runs:

```taipan
let greeting = "hello"

def greet(name: str, word: str = greeting) -> str:
    return f"{word}, {name}"

print(greet("ada"))
```

```error
main.tpn:3:34: error TP0211: 'greet' cannot use top-level variable 'greeting'
  help: pass it as a parameter, or make it a const
```

```taipan
const GREETING = "hello"

def greet(name: str, word: str = GREETING) -> str:
    return f"{word}, {name}"

print(greet("ada"))
print(greet("bob", "hi"))
```

```output
hello, ada
hi, bob
```
