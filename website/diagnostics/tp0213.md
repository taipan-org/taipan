## What it means

A type has more than one `?`, such as `int??`. An optional type `T?` holds either a `T` or `None`, and there's only one `None`, so an "optional optional" can't say anything more than `int?` already does. Python's `Optional[Optional[int]]` is the same as `Optional[int]` too. Taipan reports the doubled `?` rather than let it suggest a difference that isn't there.

## How to fix it

A doubled `?` usually comes from trying to tell "the key is missing" apart from "the key is there, holding `None`":

```taipan
def lookup(ages: dict[str, int?], name: str) -> int??:
    return ages.get(name)
```

```error
main.tpn:1:49: error TP0213: optional types cannot be nested
```

Both cases give `None` from `get`, so check whether the key is there first, with `in`:

```taipan
let ages: dict[str, int?] = {"ada": 36, "bob": None}
for name in ["ada", "bob", "cy"]:
    if name not in ages:
        print(f"{name}: unknown")
    elif ages[name] is some age:
        print(f"{name}: {age}")
    else:
        print(f"{name}: not given")
```

```output
ada: 36
bob: not given
cy: unknown
```
