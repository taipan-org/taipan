## What it means

`dotnet build` on a Taipan project couldn't find the project's main file. A Taipan project is a `.tpnproj` file, built with `dotnet build` like any .NET project. Its main file, where the program starts or the library's top-level definitions are, is the `.tpn` file with the project's name, beside the project file: `Shapes.tpn` for `Shapes.tpnproj`. The project's other `.tpn` files are its modules. If there's no file of that name, the build doesn't know which one is the main file, so it stops.

This code comes from the build, not the compiler, so `taipan run` and `taipan check` never report it.

## How to fix it

Here, the project `Shapes/Shapes.tpnproj` has its program in `Main.tpn`:

```xml
<Project Sdk="TaipanLang.Sdk/0.10.1">
  <PropertyGroup>
    <OutputType>Exe</OutputType>
  </PropertyGroup>
</Project>
```

```taipan
print("hello")
```

```sh
dotnet build
```

```text
~/.nuget/packages/taipanlang.sdk/0.10.1/Sdk/Taipan.targets(12,5): error TPN001: the main file '/work/Shapes/Shapes.tpn' was not found; set TaipanMain [/work/Shapes/Shapes.tpnproj]
```

Rename the file to `Shapes.tpn`, or name it in the project with `TaipanMain`:

```xml
<Project Sdk="TaipanLang.Sdk/0.10.1">
  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TaipanMain>Main.tpn</TaipanMain>
  </PropertyGroup>
</Project>
```

```sh
dotnet run
```

```text
hello
```

[Projects](../../guides/projects/#a-project) has how a project finds its files.
