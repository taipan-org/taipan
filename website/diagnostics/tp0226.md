## What it means

An object could be used before all its fields have a value. Taipan guarantees that a field is never read while it's unset, so by the end of `__init__`, on every path through it, each field must have been given a value or have a default. Until then, `self` can't be used for anything else, such as calling a method. In a subclass, the class sets its own fields first and then calls `super().__init__(…)`, the reverse of the usual Python order, so that methods the base class calls during its `__init__` never see the subclass's fields unset. Python allows all of these, and fails, or reads a stale value, only when it happens.

## How to fix it

`balance` is set only when the deposit is positive:

```taipan
class Account:
    owner: str
    balance: float

    def __init__(self, owner: str, deposit: float):
        self.owner = owner
        if deposit > 0:
            self.balance = deposit
```

```error
main.tpn:5:9: error TP0226: '__init__' does not set 'balance'
```

Set it on every path, here with an `else`, or give the field a default:

```taipan
class Account:
    owner: str
    balance: float

    def __init__(self, owner: str, deposit: float):
        self.owner = owner
        if deposit > 0:
            self.balance = deposit
        else:
            self.balance = 0.0

print(Account("ada", 50.0).balance, Account("bob", -5.0).balance)
```

```output
50.0 0.0
```

A subclass that calls `super().__init__` first, as Python code often does:

```taipan
class Animal:
    name: str

    def __init__(self, name: str):
        self.name = name

class Dog(Animal):
    breed: str

    def __init__(self, name: str, breed: str):
        super().__init__(name)
        self.breed = breed
```

```error
main.tpn:11:9: error TP0226: 'super().__init__' is called before 'breed' is set
```

Set the subclass's own fields, then call `super().__init__`:

```taipan
class Animal:
    name: str

    def __init__(self, name: str):
        self.name = name

class Dog(Animal):
    breed: str

    def __init__(self, name: str, breed: str):
        self.breed = breed
        super().__init__(name)

let d = Dog("rex", "beagle")
print(d.name, d.breed)
```

```output
rex beagle
```
