## What it means

A function assigns to a variable that belongs to somewhere else. A function defined inside another one can read the outer function's variables freely, but to assign to one, it must first say so with `nonlocal <name>` at the start of its body. Without it, the assignment would look like it creates a new variable of its own, which is easy to get wrong, so Taipan asks you to be explicit. A function can't assign to a top-level variable at all: pass the value in and return the new one.

The same code covers a misplaced `nonlocal`: one that isn't at the start of a nested function's body, or names a variable that no enclosing function has.

## How to fix it

Here, `bump` adds one to the `count` of the `counter` call that made it:

```taipan
def counter() -> Callable[[], int]:
    var count = 0
    def bump() -> int:
        count += 1
        return count
    return bump

let tick = counter()
tick()
print(tick())
```

```error
main.tpn:4:9: error TP0236: 'count' belongs to an enclosing function, so assigning to it needs 'nonlocal'
  help: add 'nonlocal count' at the start of this function, or use 'let' with another name for a new variable
```

Declare `count` with `nonlocal` before assigning to it. The outer variable must be a `var`:

```taipan
def counter() -> Callable[[], int]:
    var count = 0
    def bump() -> int:
        nonlocal count
        count += 1
        return count
    return bump

let tick = counter()
tick()
print(tick())
```

```output
2
```
