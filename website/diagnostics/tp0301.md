## What it means

This is a warning: an `except` clause catches every exception and throws it away. A bare `except:`, or one naming `Exception` or `BaseException`, catches not only the error you expected but also mistakes in the code, such as a wrong index or a misspelt key. If its block neither raises again nor binds the exception with `as e` and uses `e`, those mistakes disappear without a trace. The program still compiles and runs.

## How to fix it

Here, the clause is meant for a missing key, but it would hide any error at all:

```taipan
let scores = {"ada": 36}
try:
    print(scores["bob"])
except:
    pass
print("done")
```

```error
main.tpn:4:1: warning TP0301: this clause catches every exception and discards it
  help: catch a specific class, re-raise with 'raise', or bind it with 'as e' and use it
```

```output
done
```

Catch the class you expect. Anything else then still reaches you:

```taipan
let scores = {"ada": 36}
try:
    print(scores["bob"])
except KeyError as e:
    print("no score for", e)
print("done")
```

```output
no score for "bob"
done
```

If you do want to catch everything, bind it with `as e` and report it, or `raise` it again. [try and except](../../language/errors/#try-and-except) has the rules, and [the exception classes](../../library/exceptions/#the-classes) which to catch.
