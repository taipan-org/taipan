## What it means

This is a warning: a function in a test file is named like a test, but `taipan test` can't run it. `taipan test` runs every function whose name starts with `test_`, calling each with no arguments. A `test_` function that takes parameters can't be called that way, so it's skipped, and without the warning a test you meant to run would silently never run.

Only `taipan test` reports this code. To `taipan run`, a `test_` function is an ordinary function.

## How to fix it

Here, `test_math.tpn` has a test that takes the number to check:

```taipan
def double(n: int) -> int:
    return n * 2

def test_double(n: int):
    assert double(n) == n + n
```

```sh
taipan test test_math.tpn
```

```text
test_math.tpn:4:5: warning TP0303: 'test_double' takes parameters, so it isn't run as a test
no tests found
```

Give the test its values itself. A helper that takes parameters can have any name not starting with `test_`:

```taipan
def double(n: int) -> int:
    return n * 2

def check_double(n: int):
    assert double(n) == n + n

def test_double():
    for n in [0, 1, -4]:
        check_double(n)
```

```sh
taipan test test_math.tpn
```

```text
PASS test_math.tpn::test_double
1 passed, 0 failed
```

[taipan test](../../guides/testing/#taipan-test) has how tests are found and run.
