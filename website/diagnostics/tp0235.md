## What it means

An awaitable is created and then dropped without being awaited. Calling an `async` function, or a .NET method that returns a `Task`, gives an awaitable: the work it stands for, which `await` waits for and takes the result of. A call used as a statement on its own, with its result thrown away, means nothing ever waits for that work, so the program may end before it finishes and any exception it raises is lost. That is almost always a forgotten `await`, so the compiler reports it.

## How to fix it

Here, `save("draft")` is called but never awaited:

```taipan
import asyncio

async def save(name: str):
    await asyncio.sleep(0)
    print("saved", name)

save("draft")
```

```error
main.tpn:7:1: error TP0235: this awaitable is never awaited
  help: write 'await …'
```

Await it:

```taipan
import asyncio

async def save(name: str):
    await asyncio.sleep(0)
    print("saved", name)

await save("draft")
```

```output
saved draft
```

To run several at once, pass them to `asyncio.gather` and await that. [Every awaitable is awaited](../../language/async/#every-awaitable-is-awaited) has the rules.
