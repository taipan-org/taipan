## What it means

The number of things given doesn't match the number expected. Most often, a call passes more or fewer arguments than the function has parameters. The same code covers unpacking, where `let x, y = …` needs a value with exactly two elements, and patterns and type arguments with the wrong count. Python finds this when the line runs; Taipan finds it when the program compiles.

## How to fix it

<!-- no help: the message names the counts, and the fix is to match them -->

**A call with an argument missing.** `area` has two parameters:

```taipan
def area(width: int, height: int) -> int:
    return width * height

print(area(3))
```

```error
main.tpn:4:7: error TP0209: 'area' takes 2 arguments, found 1
```

Pass every argument, or give the parameter a default so a call can leave it out:

```taipan
def area(width: int, height: int = 1) -> int:
    return width * height

print(area(3, 4))
print(area(3))
```

```output
12
3
```

**Unpacking into the wrong number of names.** `point` has three elements:

```taipan
let point = (3, 4, 5)
let x, y = point
print(x, y)
```

```error
main.tpn:2:12: error TP0209: tuple[int, int, int] has 3 elements, found 2 names
```

Name every element, or collect the rest with `*`:

```taipan
let point = (3, 4, 5)
let x, y, z = point
print(x, y, z)
let first, *rest = point
print(first, rest)
```

```output
3 4 5
3 [4, 5]
```
