## What it means

The code uses a name the compiler can't find: no variable, function, class or type by that name is visible at that point. Usually it's a typo, a variable that was never declared, or one declared inside a block that has already ended. Python would raise a `NameError` when that line ran, which might be only on a path a test never takes; Taipan reports it when the program compiles.

## How to fix it

**A new variable without `let` or `var`.** In Python, the first `x = …` creates `x`. In Taipan, a variable is declared with `let` (a value that won't change) or `var` (one that can):

```taipan
total = 0
for n in [1, 2, 3]:
    total += n
print(total)
```

```error
main.tpn:1:1: error TP0201: undefined name 'total'
  help: if it's a new variable, declare it with 'let', 'var' or 'const'
main.tpn:3:5: error TP0201: undefined name 'total'
main.tpn:4:7: error TP0201: undefined name 'total'
```

```taipan
var total = 0
for n in [1, 2, 3]:
    total += n
print(total)
```

```output
6
```

**A misspelled name.** Check the spelling against the declaration:

```taipan
let names = ["Ada", "Grace"]
print(len(nmes))
```

```error
main.tpn:2:11: error TP0201: undefined name 'nmes'
  help: did you mean 'names'?
```

```taipan
let names = ["Ada", "Grace"]
print(len(names))
```

```output
2
```

**A type name from another language.** Taipan's types are Python's: `str`, not `string`; `float`, not `Float` or `double`:

```taipan
def greet(name: string) -> string:
    return "hi " + name

print(greet("Ada"))
```

```error
main.tpn:1:17: error TP0201: undefined type 'string'
  help: use 'str'
main.tpn:1:28: error TP0201: undefined type 'string'
  help: use 'str'
```

```taipan
def greet(name: str) -> str:
    return "hi " + name

print(greet("Ada"))
```

```output
hi Ada
```

A name declared inside an `if` or a loop is gone after that block ends; declare it before the block to use it afterwards. [Variables](../../language/variables/#scope) explains where a name is visible.
