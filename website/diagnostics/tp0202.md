## What it means

The code assigns a new value to something that can't change. A variable declared with `let` keeps the value it was given, and so do a function's parameters, a `for` loop's variable and a `const`. Taipan makes you say up front which variables change, with `var`, so that a reader knows every other name means the same thing throughout. The same code covers changing a character of a `str` or an element of a tuple, which can't be changed either.

## How to fix it

`count` is declared with `let`, so it can't be assigned:

```taipan
let count = 0
count = count + 1
print(count)
```

```error
main.tpn:2:1: error TP0202: cannot assign to 'count': it is a let binding
  help: declare it with 'var'
```

Declare it with `var`:

```taipan
var count = 0
count = count + 1
print(count)
```

```output
1
```

For a parameter, copy it into a `var` first, as in `var n = start`. For a string or a tuple, build a new one, as in `name = name.replace("a", "o")` with `var name`. [Variables](../../language/variables/) describes `let`, `var` and `const`.
