## What it means

A module has code at its top level that would run, such as a `print(…)`, a `let` or a `var`, or an `if`. Only the file you run, the main file, has code that runs; a module only holds declarations: imports, functions, classes, enums, constants, protocols and type aliases. In Python, importing a module runs its top level, so importing can print or change things as a side effect. Taipan rules that out. The same holds for a library's main file and a Python extension module.

The same code also reports **importing the main file**, from a module or from the main file itself. The main file runs once, as the program, so it has nothing to export; in Python, importing it would run it a second time. Move what both files need into a module that each imports.

## How to fix it

This module sets a value with `let`, and tries out its function with a `print`:

```taipan title="shapes.tpn"
let default_height = 1.0

def area(width: float, height: float) -> float:
    return width * height

print(area(2.0, 3.0))
```

```taipan
import shapes

print(shapes.area(4.0, 5.0))
```

```error
shapes.tpn:1:1: error TP0222: only the main file can have top-level statements
  help: make it a 'const', or move it into a function or the main file
shapes.tpn:6:1: error TP0222: only the main file can have top-level statements
  help: make it a 'const', or move it into a function or the main file
```

Make module-wide values `const`s, and move code that should run into the main file:

```taipan title="shapes.tpn"
const DEFAULT_HEIGHT = 1.0

def area(width: float, height: float = DEFAULT_HEIGHT) -> float:
    return width * height
```

```taipan
import shapes

print(shapes.area(2.0, 3.0))
print(shapes.area(4.0))
```

```output
6.0
4.0
```
