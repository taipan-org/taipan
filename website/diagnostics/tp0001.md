## What it means

A line is indented with a tab character. Taipan uses indentation to decide which lines belong to an `if`, a loop or a function, and it only counts spaces. A tab can look like four spaces in one editor and eight in another, so a file that mixes them can mean something different from what it shows. Python accepts tabs; Taipan rejects them when the program compiles, so the indentation you see is the indentation it reads.

## How to fix it

Here the `print` line starts with a tab:

```taipan
let n = 3
if n > 2:
	print("big")
```

```error
main.tpn:3:1: error TP0001: tab in indentation
  help: indent with spaces
```

Indent with spaces instead. Four per level is the usual choice:

```taipan
let n = 3
if n > 2:
    print("big")
```

```output
big
```

Most editors can insert spaces when you press Tab, and convert a file's tabs to spaces. A tab elsewhere on a line, such as inside a string, is fine. [Control flow](../../language/control-flow/) shows how blocks are indented.
