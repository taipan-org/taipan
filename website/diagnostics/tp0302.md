## What it means

This is a warning: a library defines something public that it can't make available to the code that uses it. `taipan build --library` compiles a file into a .NET library, whose public functions, classes and constants C# and other .NET code can call. A few Taipan features have no .NET form, such as a type parameter with a bound or an optional of a type parameter (`T?`), and anything that uses one can't be exported either. Python extension modules (`--python-extension`) have limits of their own: a generic or `async` function, say, can't be given to Python. The library still builds, without that definition, and the message gives the reason.

`taipan run` doesn't report this code, since a program exports nothing.

## How to fix it

Here, `shapes.tpn` is a library, and `largest` has a type parameter bounded by `Comparable`:

```taipan
def area(width: float, height: float) -> float:
    return width * height

def largest[T: Comparable](xs: list[T]) -> T:
    var best = xs[0]
    for x in xs:
        if best < x:
            best = x
    return best

def biggest_area(sizes: list[float]) -> float:
    return largest(sizes)
```

```sh
taipan build shapes.tpn --library -o out
```

```text
shapes.tpn:4:5: warning TP0302: 'largest' is not exported: its type parameter 'T' has a bound
  help: rename it '_largest' to keep it private
built out/shapes.dll
```

If .NET code doesn't need it, make it private by starting its name with `_`. The functions that use it can still be exported:

```taipan
def area(width: float, height: float) -> float:
    return width * height

def _largest[T: Comparable](xs: list[T]) -> T:
    var best = xs[0]
    for x in xs:
        if best < x:
            best = x
    return best

def biggest_area(sizes: list[float]) -> float:
    return _largest(sizes)
```

```sh
taipan build shapes.tpn --library -o out
```

```text
built out/shapes.dll
```

If .NET code does need it, change it to use only types .NET has, here with `list[float]` in place of `list[T]`. [Building .NET libraries](../../guides/dotnet-libraries/#what-c-sees) has what a library exports.
