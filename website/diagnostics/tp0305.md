## What it means

This is a warning: arithmetic comes straight after `??`, on its right. `a ?? b` gives `a`, or `b` when `a` is `None`, and `??` binds more loosely than the arithmetic operators, so `x ?? 0 + 1` means `x ?? (0 + 1)`: the `+ 1` only happens when `x` is `None`. Code that reads like that usually meant `(x ?? 0) + 1`, so the compiler points it out. The program still compiles and runs.

## How to fix it

Here, the count should be one more than the stock, but the `+ 1` only applies to the default:

```taipan
let stock = {"apples": 3}
let count = stock.get("apples") ?? 0 + 1
print(count)
```

```error
main.tpn:2:33: warning TP0305: '??' binds more loosely than '+', so this is 'stock.get("apples") ?? (0 + 1)'
  help: write '(stock.get("apples") ?? 0) + 1' if you meant that, or add the parentheses to keep this
```

```output
3
```

Put parentheses around the `??`, so the default is given first and then added to:

```taipan
let stock = {"apples": 3}
let count = (stock.get("apples") ?? 0) + 1
print(count)
```

```output
4
```

If the default really is `0 + 1`, write `stock.get("apples") ?? (0 + 1)`, and the warning goes away. [Precedence](../../language/operators/#precedence) lists every operator in order.
