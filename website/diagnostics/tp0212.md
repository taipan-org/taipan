## What it means

A chain of comparisons includes `in`, `not in`, `is` or `is not`. Taipan, like Python, reads `a < b < c` as `a < b and b < c`. That's handy for numbers, but with `in` or `is` it gives results almost nobody expects: `name in allowed == True` means `name in allowed and allowed == True`, which is always `False`. Python runs it anyway; Taipan stops and asks you to say what you mean.

## How to fix it

Here the chain compares the list itself with `True`:

```taipan
let allowed = ["ada", "bob"]
let name = "ada"
print(name in allowed == True)
```

```error
main.tpn:3:23: error TP0212: a chained comparison can't include 'in' or 'is'
  help: split it with 'and'
```

`in` already gives a `bool`, so drop the `== True`. When you do want two tests, join them with `and`:

```taipan
let allowed = ["ada", "bob"]
let banned = ["eve"]
let name = "ada"
print(name in allowed)
print(name in allowed and name not in banned)
```

```output
True
True
```
