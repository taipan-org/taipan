## What it means

This is a warning: some code can never run. It comes straight after a `return`, `raise`, `break` or `continue`, which always leaves before reaching it, or it's a `match` arm or `except` clause that an earlier one already handles everything for. The program still compiles and runs, but the code is dead, which usually means it's in the wrong place or a condition is wrong.

## How to fix it

Here, the `print` comes after the function has already returned on every path:

```taipan
def sign(n: int) -> str:
    if n < 0:
        return "negative"
    return "not negative"
    print("checked", n)

print(sign(-3))
```

```error
main.tpn:5:5: warning TP0300: unreachable code
  help: delete it, or move it where it can run
```

```output
negative
```

Move the code to where it runs, or delete it:

```taipan
def sign(n: int) -> str:
    print("checked", n)
    if n < 0:
        return "negative"
    return "not negative"

print(sign(-3))
```

```output
checked -3
negative
```

For an unreachable `except` clause, put the more specific class first; for a `match` arm, put it before the arm that already matches it. [try and except](../../language/errors/#try-and-except) and [match](../../language/match/) have the details.
