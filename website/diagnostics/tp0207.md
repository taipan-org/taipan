## What it means

A name is declared inside a block while a name just like it is already visible from outside that block. Python has no blocks of its own, so reusing a name inside an `if` or a loop silently changes the outer variable. Taipan gives each block its own names instead, and rather than let two variables with one name exist side by side, it rejects the second, so a name means one thing throughout a function or the top level.

A `for` loop's variable counts as declared inside the loop, so `for total in …` after `let total` is this error too.

## How to fix it

The inner `let price` reuses the outer `price`:

```taipan
let price = 100
if price > 50:
    let price = price - 10
    print(price)
```

```error
main.tpn:3:9: error TP0207: 'price' shadows an outer binding
  help: give it another name
```

Give the new value its own name:

```taipan
let price = 100
if price > 50:
    let discounted = price - 10
    print(discounted)
```

```output
90
```

To change the outer variable instead, declare it with `var` and assign it without `let`: `price = price - 10`. A function's parameters and locals may reuse a top-level name, since a function can't see the top level's variables. [Variables](../../language/variables/#scope) has the rules for scope.
