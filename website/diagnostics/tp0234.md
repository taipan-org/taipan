## What it means

The program creates an object of an abstract class. A class that derives from `ABC` can mark methods `@abstractmethod`: it declares them without a real body, and leaves each class derived from it to provide them. A class is abstract while any of those methods is still missing, either because it declares them itself or because it inherits them without overriding them. Making an object of it would leave those methods with nothing to run, so the compiler stops it. The help line names the methods that are still missing.

## How to fix it

Here, `Square` derives from `Shape` but doesn't define `area`, so `describe` would have nothing to call:

```taipan
class Shape(ABC):
    @abstractmethod
    def area(self) -> float: ...

    def describe(self) -> str:
        return f"area {self.area()}"

class Square(Shape):
    def perimeter(self) -> float:
        return 8.0

let s = Square()
print(s.describe())
```

```error
main.tpn:12:9: error TP0234: cannot instantiate abstract class 'Square'
  help: it does not implement 'Shape.area'
```

Override every abstract method in the class you create, marking each `@override`:

```taipan
class Shape(ABC):
    @abstractmethod
    def area(self) -> float: ...

    def describe(self) -> str:
        return f"area {self.area()}"

class Square(Shape):
    @override
    def area(self) -> float:
        return 4.0

let s = Square()
print(s.describe())
```

```output
area 4.0
```

The same code is reported for a class method that calls `cls(…)` on an abstract class, since `cls` may be that class. [Abstract classes](../../language/classes/#abstract-classes-abc-and-abstractmethod) has the rules.
