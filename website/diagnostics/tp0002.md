## What it means

A line is indented less than the line before it, but not by the right amount to line up with any block it could be returning to. When an indented block ends, the next line has to start at exactly the same column as one of the lines around the block, such as the `if` or `def` that opened it. A line in between belongs to no block, so the compiler can't tell where it goes.

## How to fix it

Here the last line is indented two spaces: less than the `print` inside the `if`, more than the `if` itself:

```taipan
let n = 3
if n > 2:
    print("big")
  print("done")
```

```error
main.tpn:4:3: error TP0002: dedent does not match any outer indentation level
  help: indent it as a line of the block it belongs to
```

Line it up with the block it belongs to. To run it after the `if`, start it at the `if`'s column; to run it inside, indent it as far as the `print` above it:

```taipan
let n = 3
if n > 2:
    print("big")
print("done")
```

```output
big
done
```
