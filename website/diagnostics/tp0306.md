## What it means

This is a warning: an `except` clause names one of Taipan's built-in exception classes, such as `KeyError`, around code that calls into Python, and Python raises its own class of that name. An exception raised in Python code reaches Taipan as a `PythonError`, not as Taipan's `KeyError`, so the clause looks as if it handles a missing key from Python, but it never will. The exception passes it by and carries on up. The program still compiles and runs.

## How to fix it

Here, `doc` is a Python dict, so a missing `"age"` raises Python's `KeyError`, which this clause doesn't catch. It works for now only because the key is there:

```taipan
from python import json

def age_of(text: str) -> str:
    let doc = json.loads(text)
    try:
        return f"{doc["age"]}"
    except KeyError as e:
        return "unknown"

print(age_of("{\"name\": \"ada\", \"age\": 36}"))
```

```error
main.tpn:7:12: warning TP0306: a Python 'KeyError' arrives as PythonError, which this doesn't catch
  help: catch 'builtins.KeyError' after 'from python import builtins', or 'PythonError'
```

```output
36
```

Catch Python's own class, from its `builtins` module:

```taipan
from python import json
from python import builtins

def age_of(text: str) -> str:
    let doc = json.loads(text)
    try:
        return f"{doc["age"]}"
    except builtins.KeyError as e:
        return "unknown"

print(age_of("{\"name\": \"ada\", \"age\": 36}"))
print(age_of("{\"name\": \"bob\"}"))
```

```output
36
unknown
```

`except PythonError as e:` catches every exception from Python, with its class's name in `e.type`. [Python exceptions](../../guides/python/#python-exceptions) has the details.
