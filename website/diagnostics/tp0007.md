## What it means

A number is written in a way Taipan doesn't accept. Integers are written in decimal, with `_` allowed only between two digits (`1_000_000`), and a number with more than one digit can't start with `0`. A number can't run straight into a letter, as in `12abc`, and an exponent needs digits, as in `1e9`, not `1e`. Python's `0x`, `0o` and `0b` prefixes aren't part of the language either.

## How to fix it

Here `0xFF` is written in hexadecimal and `07` has a leading zero:

```taipan
let mask = 0xFF
let month = 07
print(mask, month)
```

```error
main.tpn:1:12: error TP0007: invalid number literal
  help: numbers are decimal; write 255
main.tpn:2:13: error TP0007: invalid number literal
  help: leading zeros aren't allowed; write 7
```

Write them in decimal, without the leading zero:

```taipan
let mask = 255
let month = 7
print(mask, month)
```

```output
255 7
```

A float needs a digit before its point: write `0.5`, since `.5` is a syntax error (`TP0100`). [Numbers](../../library/numbers/) describes `int` and `float`.
