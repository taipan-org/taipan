## What it means

A decorator, the `@name` line before a `def` or `class`, isn't one Taipan has, or is in a place it doesn't apply. In Python a decorator is any function that wraps another, but Taipan has only a fixed set, each checked by the compiler: `@dataclass`, `@final` and `@total_ordering` on a class, and `@override`, `@property`, `@<name>.setter`, `@staticmethod`, `@classmethod`, `@abstractmethod` and `@final` on a method. A top-level function takes no decorators. The same error covers a decorator written twice, and two that can't go together, such as `@staticmethod` and `@classmethod`.

## How to fix it

Python's `@cache` doesn't exist in Taipan:

```taipan
@cache
def fib(n: int) -> int:
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print(fib(50))
```

```error
main.tpn:1:1: error TP0224: unknown decorator '@cache'
```

Write what the decorator would do in the function itself. Here a dict remembers the answers:

```taipan
let known: dict[int, int] = {}

def fib(n: int) -> int:
    if n < 2:
        return n
    if known.get(n) is some cached:
        return cached
    let value = fib(n - 1) + fib(n - 2)
    known[n] = value
    return value

print(fib(50))
```

```output
12586269025
```
