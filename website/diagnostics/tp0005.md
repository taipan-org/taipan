## What it means

A string has a backslash followed by something that isn't an escape sequence. Inside a string, a backslash starts a special character: `\n` is a line break, `\t` a tab, `\\` a backslash and `\"` a quote. Any other letter after a backslash, such as `\d` or `\q`, is an error. Python keeps the backslash in that case and only warns, which hides mistakes like a Windows path whose `\n` quietly turns into a line break. Taipan reports it when the program compiles.

## How to fix it

In this path, `\d` isn't an escape (and `\n` is one, which isn't what was meant either):

```taipan
let folder = "C:\data\new"
print(folder)
```

```error
main.tpn:1:17: error TP0005: invalid escape sequence '\d'
  help: write '\\' for a backslash, or use a raw string: r"…"
```

Write each backslash as `\\`, or use a raw string, `r"…"`, in which a backslash is just a backslash:

```taipan
let folder = "C:\\data\\new"
let raw = r"C:\data\new"
print(folder)
print(raw)
```

```output
C:\data\new
C:\data\new
```

The same code covers `\x`, `\u` and `\U` without enough hex digits, and `\{` or `\}`: write `{{` and `}}` in an f-string, or just `{` and `}` elsewhere. [Escape sequences](../../language/strings-and-f-strings/#escape-sequences) lists every one.
