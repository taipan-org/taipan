## What it means

A call passes an argument by name, `name=value`, that the function doesn't accept. Usually the name is misspelled, or it belongs to a different function. Some calls take no names at all: a function stored in a variable or passed as an argument (it has a type, not parameter names), many built-in functions and methods, and parameters listed before a `/`. Python reports the same mistake with a `TypeError` when the call runs; Taipan reports it when the program compiles.

## How to fix it

`sorted`'s parameter is `reverse`, not `reversed`:

```taipan
let scores = [3, 9, 5]
print(sorted(scores, reversed=True))
```

```error
main.tpn:2:22: error TP0218: 'sorted' has no parameter 'reversed'
```

Use the parameter's real name, or pass the argument by position where the function takes no names:

```taipan
let scores = [3, 9, 5]
print(sorted(scores, reverse=True))
```

```output
[9, 5, 3]
```
