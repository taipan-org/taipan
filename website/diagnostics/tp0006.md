## What it means

An f-string, a string written `f"…"`, is put together from text and *holes*: each `{…}` holds an expression whose value goes into the string. This error means the braces don't form a valid hole. The usual causes are a hole with nothing in it, `{}`, a lone `}`, an f-string inside another f-string's hole, or a conversion other than `!r` or `!s` after the expression.

## How to fix it

To show a brace itself, it has to be doubled. Here `{}` is read as an empty hole:

```taipan
let lang = "Taipan"
print(f"In {lang}, {} is an empty dict.")
```

```error
main.tpn:2:20: error TP0006: empty f-string hole
  help: put an expression in the braces, or write '{{' and '}}' for braces
```

Write `{{` for `{` and `}}` for `}`:

```taipan
let lang = "Taipan"
print(f"In {lang}, {{}} is an empty dict.")
```

```output
In Taipan, {} is an empty dict.
```

A lone `}`, as in `f"{score}}"`, gives `single '}' is not allowed in an f-string`, and is fixed the same way. For a nested f-string, compute the inner string with `let` first and put its name in the hole. [Strings and f-strings](../../language/strings-and-f-strings/#holes) has the rules for holes.
