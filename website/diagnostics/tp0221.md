## What it means

An `import` names a module Taipan can't find. A module is a `.tpn` file in the same directory as the main file, named after the file: `shapes.tpn` is the module `shapes`. The help line shows the file Taipan looked for. Usually the name is misspelled, or the file is somewhere else. Python's standard library modules, such as `random` or `json`, aren't Taipan modules: they're imported with `from python import random`, as the help says. A few Python modules exist only to provide names Taipan has built in: `typing`, `typing_extensions`, `dataclasses`, `abc` and `__future__`. Importing one gets its own message, and the fix is to delete the import, since `Callable`, `@dataclass`, `ABC` and `Protocol` need none. `from enum import Enum` is a syntax error instead, because `enum` is a keyword: an enum is declared with `enum Name:`.

## How to fix it

With this module beside the main file:

```taipan title="shapes.tpn"
def area(width: float, height: float) -> float:
    return width * height
```

the import below misspells its name:

```taipan
import shape

print(shape.area(2.0, 3.0))
```

```error
main.tpn:1:8: error TP0221: module 'shape' not found
  help: looked for shape.tpn; a Python module is imported with 'from python import shape'
```

Use the file's name, without `.tpn`:

```taipan
import shapes

print(shapes.area(2.0, 3.0))
```

```output
6.0
```
