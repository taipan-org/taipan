## What it means

The file contains a character that isn't part of the language anywhere outside a string or a comment, such as `$`, `!` on its own, or `;`. The compiler can't make it into a name, number, operator or piece of punctuation, so it stops there.

The `;` is the one Python programmers meet most often: Python lets you separate two statements on one line with it, and Taipan doesn't.

## How to fix it

Here two statements share a line:

```taipan
let total = 2 + 3; print(total)
```

```error
main.tpn:1:18: error TP0004: invalid character ';'
  help: write each statement on its own line
```

Put each statement on its own line:

```taipan
let total = 2 + 3
print(total)
```

```output
5
```

For other characters, check what you meant: `!=` is "not equal", `not` negates a `bool`, and a `$` can only appear inside a string or a comment. [Operators](../../language/operators/) lists every operator Taipan has.
