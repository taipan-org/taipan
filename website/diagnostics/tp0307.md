## What it means

This is a warning: a `let` or `var` holds an awaitable that's never read. Calling an `async` function starts its work and gives an awaitable for it, which `await` waits for. If the variable holding it is never used again, nothing ever waits for that work, so the program may end before it finishes, and an exception it raises is only reported when the program ends. The program still compiles and runs.

## How to fix it

Here, `first` is started but never awaited:

```taipan
import asyncio

async def fetch(name: str) -> int:
    await asyncio.sleep(0)
    return len(name)

async def main() -> None:
    let first = fetch("ada")
    let second = fetch("grace")
    print(await second)

asyncio.run(main())
```

```error
main.tpn:8:9: warning TP0307: 'first' is never awaited
  help: await it, or pass it to 'asyncio.gather'
```

```output
5
```

Await it, or, to wait for several at once, pass them to `asyncio.gather`:

```taipan
import asyncio

async def fetch(name: str) -> int:
    await asyncio.sleep(0)
    return len(name)

async def main() -> None:
    let first = fetch("ada")
    let second = fetch("grace")
    print(await asyncio.gather(first, second))

asyncio.run(main())
```

```output
[3, 5]
```

[Every awaitable is awaited](../../language/async/#every-awaitable-is-awaited) has the rules.
