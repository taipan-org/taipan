## What it means

This is a warning: repeating a list with `*` copies references to one inner list, dict or set, not the thing itself. `[[0] * 3] * 2` makes a list of two elements that are the same inner list, so changing `grid[0][0]` changes `grid[1][0]` too. That's rarely what's meant, so the compiler warns when the element being repeated is a new list, dict or set. The program still compiles and runs, as Python would.

## How to fix it

Here, setting one cell of the grid sets it in every row:

```taipan
let grid = [[0] * 3] * 2
grid[0][0] = 1
print(grid)
```

```error
main.tpn:1:12: warning TP0304: every copy shares the same list
  help: build each one separately, with a comprehension: [… for _ in range(…)]
```

```output
[[1, 0, 0], [1, 0, 0]]
```

Build each row separately, with a list comprehension, so each one is a new list:

```taipan
let grid = [[0] * 3 for _ in range(2)]
grid[0][0] = 1
print(grid)
```

```output
[[1, 0, 0], [0, 0, 0]]
```

Repeating a number, string or tuple, as `[0] * 3` does, is fine, since those can't be changed in place. [List operators](../../library/list/#operators) has the details.
