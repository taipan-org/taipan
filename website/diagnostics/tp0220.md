## What it means

A type parameter's bound or list of allowed types isn't one Taipan accepts. A bound, `[T: Comparable]`, must be a protocol or a class, and goes only on a function's type parameters, not a class's or an enum's. A list of allowed types, `[N: (int, float)]`, needs at least two types, none of them optional. A built-in type such as `int` is neither, so it can't be a bound.

## How to fix it

A function that should work for whole numbers and decimals can't bound `N` by `int`:

```taipan
def total[N: int](xs: list[N]) -> N:
    var sum = xs[0]
    for x in xs[1:]:
        sum = sum + x
    return sum

print(total([1, 2, 3]))
```

```error
main.tpn:1:14: error TP0220: 'int' is not a protocol
  help: a bound is a protocol, as '[T: Comparable]'; for a few types, write a constraint: '[T: (int, float)]'
main.tpn:4:15: error TP0200: operator '+' cannot be applied to N and N
```

List the types it may be, in parentheses:

```taipan
def total[N: (int, float)](xs: list[N]) -> N:
    var sum = xs[0]
    for x in xs[1:]:
        sum = sum + x
    return sum

print(total([1, 2, 3]), total([0.5, 0.25]))
```

```output
6 0.75
```

A class's type parameter can't have a bound:

```taipan
class Ranking[T: Comparable]:
    items: list[T]

    def __init__(self, items: list[T]):
        self.items = items
```

```error
main.tpn:1:18: error TP0220: bounds are only supported on functions
  help: put the bound on the methods that need it
```

Leave the class's `T` unbounded, and put the bound on the functions that need it:

```taipan
class Ranking[T]:
    items: list[T]

    def __init__(self, items: list[T]):
        self.items = items

def best[T: Comparable](r: Ranking[T]) -> T:
    return max(r.items)

print(best(Ranking([3, 9, 4])))
print(best(Ranking(["pear", "apple"])))
```

```output
9
pear
```
