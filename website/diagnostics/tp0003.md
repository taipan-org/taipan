## What it means

A string starts with a quote but never ends. An ordinary string, in `"…"` or `'…'`, has to close on the line it starts on, and a triple-quoted one, in `"""…"""`, before the end of the file. The error points at the opening quote, so look along that line for the missing closing one.

## How to fix it

The closing quote after `Ada` is missing:

```taipan
let name = "Ada
print(name)
```

```error
main.tpn:1:12: error TP0003: unterminated string
  help: close it with " on the same line, or use triple quotes for a string over several lines
```

Close the string with the same kind of quote that opened it:

```taipan
let name = "Ada"
print(name)
```

```output
Ada
```

A string that should span several lines needs triple quotes, or `\n` where each line break goes. A raw string can't end in a single backslash, as in `r"C:\"`, since the backslash still keeps the quote after it from ending the string. [Strings and f-strings](../../language/strings-and-f-strings/) has every kind of string literal.
