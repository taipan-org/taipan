## What it means

The program uses something that a native build can't include. `taipan build --native` compiles a program ahead of time into a single executable that runs without .NET installed. That leaves out two things: Python, since a native program can't load a Python installation, and .NET members that create code or look types up by name while the program runs, such as `Type.GetType` and `Assembly.GetTypes`, since the native compiler only keeps what it can see the program use. A Python extension module, built with `--python-extension`, is native too, so it can't use Python interop itself, and can only pass Python objects along.

`taipan run` and an ordinary `taipan build` don't report this code, since those programs run on .NET.

## How to fix it

Here, a program reads JSON with Python's `json` module:

```taipan
from python import json

let doc = json.loads("{\"name\": \"ada\"}")
print(doc["name"])
```

Building it natively fails:

```sh
taipan build main.tpn --native -o out
```

```text
main.tpn:1:1: error TP0233: a native program can't use Python
  help: build it without '--native'
```

Either build it without `--native`, or do the work with something a native program has. Here, .NET's own JSON reader does the same:

```taipan
from dotnet.System.Text.Json import JsonDocument

let doc = JsonDocument.Parse("{\"name\": \"ada\"}")
print(doc.RootElement.GetProperty("name").GetString())
```

```sh
taipan build main.tpn --native -o out
./out/main
```

```text
built out/main
ada
```

For a .NET member, the message gives .NET's reason it can't be used natively, which usually names a replacement. [Native builds](../../guides/native/) has what a native program can use.
