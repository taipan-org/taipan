## What it means

A function says it returns a value, with `-> int` or another type after its parameters, but some way through its body reaches the end without a `return`. Python would return `None` there, which the caller didn't expect. Taipan checks every path when the program compiles. It doesn't work out which conditions can be true together, so an `if` and an `elif` that between them cover everything still leave a path past both.

## How to fix it

The compiler treats the `elif` as possibly false, so the end of `grade` can be reached:

```taipan
def grade(score: int) -> str:
    if score >= 50:
        return "pass"
    elif score < 50:
        return "fail"

print(grade(70))
```

```error
main.tpn:1:5: error TP0208: not all paths in 'grade' return a value
```

Make the last case an `else`, or end the function with a `return`:

```taipan
def grade(score: int) -> str:
    if score >= 50:
        return "pass"
    else:
        return "fail"

print(grade(70))
print(grade(20))
```

```output
pass
fail
```

A `raise` also ends a path, and so does a `match` whose every arm returns or raises. [`return`](../../language/functions/#return) describes the rule.
