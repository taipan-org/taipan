## What it means

A `match` doesn't cover every value its subject could have. Some value would reach the end without matching any arm, and Taipan doesn't let it fall through silently: the compiler lists patterns for the values left over. This is most useful with enums, since adding a variant to one points out every `match` that needs a new arm.

## How to fix it

`Light` has three variants, and the `match` handles only two:

```taipan
enum Light:
    Red
    Yellow
    Green

def action(light: Light) -> str:
    match light:
        Red:
            return "stop"
        Green:
            return "go"

print(action(Yellow))
```

```error
main.tpn:7:5: error TP0204: non-exhaustive match (missing: Yellow)
  help: add an arm for each, or '_:' for the rest
```

Add an arm for each missing pattern:

```taipan
enum Light:
    Red
    Yellow
    Green

def action(light: Light) -> str:
    match light:
        Red:
            return "stop"
        Yellow:
            return "slow down"
        Green:
            return "go"

print(action(Yellow))
```

```output
slow down
```

An `int` or a `str` has too many values to list, so the compiler asks for `_`, which matches anything, as the last arm:

```taipan
let code = 404
let text = match code:
    200: "ok"
    404: "not found"
print(text)
```

```error
main.tpn:2:12: error TP0204: non-exhaustive match (missing: _)
  help: add an arm for each, or '_:' for the rest
```

```taipan
let code = 404
let text = match code:
    200: "ok"
    404: "not found"
    _: "other"
print(text)
```

```output
not found
```
