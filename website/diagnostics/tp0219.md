## What it means

A generic function calls itself with a bigger type each time, so it would need endless versions of itself. Taipan compiles a separate copy of a generic function for each type it's used with. If `nest[T]` calls `nest` with a `list[T]`, the `int` copy needs a `list[int]` copy, which needs a `list[list[int]]` copy, and so on without end. Taipan stops once the chain is 32 levels deep and reports the call that started it.

## How to fix it

Each call wraps `x` in one more list:

```taipan
def nest[T](x: T, n: int) -> str:
    if n == 0:
        return str(x)
    return nest([x], n - 1)

print(nest(1, 3))
```

```error
main.tpn:6:1: error TP0219: instantiating 'nest' needs 'nest[list[list[list[...]]]]', which is too deep
  help: the recursive call instantiates it with a bigger type each time; call it with the same type, or use a non-generic helper
```

Make each recursive call use the same type, or, as here, use a loop instead of recursion:

```taipan
def nest[T](x: T, n: int) -> str:
    var text = str(x)
    for _ in range(n):
        text = f"[{text}]"
    return text

print(nest(1, 3))
```

```output
[[[1]]]
```
