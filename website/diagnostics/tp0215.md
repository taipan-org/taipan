## What it means

A statement that only makes sense in a certain place is somewhere else. `break` and `continue` belong inside a loop, `return` inside a function, a bare `raise` inside an `except` block, and `await` inside an `async def` (or at the main file's top level). A `return`, `break` or `continue` inside a `finally` block is also an error, since it would silently throw away an exception on its way out. Python rejects most of these too; a bare `raise` outside `except` fails there only when it runs.

## How to fix it

A `return` at the top level of a file, to stop the program early, has no function to return from:

```taipan
let names = ["ada", "bob"]
if len(names) == 0:
    print("nothing to do")
    return
for name in names:
    print(name)
```

```error
main.tpn:4:5: error TP0215: 'return' outside a function
  help: to end the program, call sys.exit()
```

Call `sys.exit` to stop the program, or put the rest of the code in an `else`:

```taipan
import sys

let names = ["ada", "bob"]
if len(names) == 0:
    print("nothing to do")
    sys.exit(0)
for name in names:
    print(name)
```

```output
ada
bob
```

`await` in a function that isn't `async`:

```taipan
import asyncio

async def fetch(n: int) -> int:
    await asyncio.sleep(0.01)
    return n * 2

def total() -> int:
    return await fetch(1)

print(total())
```

```error
main.tpn:8:12: error TP0215: 'await' outside an async function
  help: mark the function 'async def'
```

Make the function `async def`, and `await` it where it's called:

```taipan
import asyncio

async def fetch(n: int) -> int:
    await asyncio.sleep(0.01)
    return n * 2

async def total() -> int:
    return await fetch(1) + await fetch(2)

print(await total())
```

```output
6
```
