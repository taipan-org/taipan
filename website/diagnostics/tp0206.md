## What it means

The compiler can't work out a value's type from the value alone. A variable usually takes its type from its first value: `[1, 2]` is a `list[int]`. An empty list `[]`, an empty dict `{}` or a plain `None` gives no clue what it will hold, and Taipan doesn't guess from later lines, so the type has to be written down.

## How to fix it

`names` starts empty, so its element type is unknown:

```taipan
var names = []
names.append("Ada")
print(names)
```

```error
main.tpn:1:13: error TP0206: cannot infer the type of an empty list
  help: add a type annotation
```

Annotate the variable with the type it will hold:

```taipan
var names: list[str] = []
names.append("Ada")
print(names)
var ages: dict[str, int] = {}
ages["Ada"] = 36
print(ages)
```

```output
["Ada"]
{"Ada": 36}
```

A variable that starts as `None` takes an optional type, as in `var best: int? = None`, and a lambda whose parameters can't be inferred takes them from a `Callable` annotation. [Types and inference](../../language/variables/#types-and-inference) explains which types are inferred.
